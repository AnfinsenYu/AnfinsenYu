## 🚀 Featured Project

### 🔊 VoiceMind（核心项目）

> 一个面向应用层的语音智能服务（ASR + LLM）

---

### 🧠 功能模块

- 🎤 **ASR（语音识别）**
  - 基于 SenseVoice / DashScope
  - 支持音频转文本

- 🧾 **LLM总结**
  - 基于大模型自动提取关键信息
  - 输出结构化摘要

- ⚙️ **Backend API**
  - 提供统一接口给前端/应用调用
  - 支持 Demo / Mock / 真实服务切换

---

### 🏗 系统架构（简化）
Audio Input
↓
ASR Service (SenseVoice)
↓
Text
↓
LLM (DeepSeek / Qwen)
↓
Summary Output
↓
API Response
